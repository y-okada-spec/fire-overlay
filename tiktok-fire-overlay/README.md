# いいねで炎が大きくなる TikTok LIVE オーバーレイ

視聴者がタップ（いいね）するほど炎が大きく・激しくなり、時間が経つと少しずつ小さくなります。

## 必要なもの
- Windows PC
- [Node.js](https://nodejs.org/)（LTS版）
- TikTok LIVE Studio または OBS

## 起動
1. `start.bat` をダブルクリック
2. 自分の TikTok ユーザー名（@なし）を入力
3. 「接続しました」と出れば OK（**LIVE配信を開始してから**起動してください）

## 配信ソフトに追加
- **TikTok LIVE Studio**: ソース追加 →「リンク」→ `http://localhost:8080/`
- **OBS**: ソース追加 →「ブラウザ」→ URL `http://localhost:8080/`、幅 1080 / 高さ 1920 など

背景は透明なので、映像の上にそのまま重なります。

## テスト
- `http://localhost:8080/?test` をブラウザで開く → クリック / スペースキーでいいね、`b`キーで15連打
- `http://localhost:8080/like?n=30` を開くと、配信ソフト上のオーバーレイに30いいねが届きます

## 調整（URLの後ろに付ける）
| パラメータ | 意味 | 初期値 |
|---|---|---|
| `max` | 最大火力に必要ないいね数 | 300 |
| `decay` | 1秒あたりに冷める量（0で冷めない） | 4 |
| `perLike` | 1いいねで増える量 | 1 |
| `names=0` | いいねした人の名前を非表示 | 表示 |
| `hud=0` | レベル・カウント表示を非表示 | 表示 |

例: `http://localhost:8080/?max=1000&decay=8`（人が多い配信向け）
